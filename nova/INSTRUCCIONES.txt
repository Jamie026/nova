================================================================================
NOVA — AGENTE DE VOZ DE ESCRITORIO
Instrucciones de instalación y uso
================================================================================

Este archivo lo tiene todo: qué instalar, qué poner en el .env, qué ejecutar y
qué hacer cuando algo falle. Si sólo lees una sección, lee la 2 y la 3.

Sistema operativo: Windows 11 (también arranca en Windows 10).
El núcleo es multiplataforma, pero el control de aplicaciones y del escritorio
está implementado sólo para Windows por ahora.


================================================================================
1. LO QUE TIENES QUE INSTALAR ANTES
================================================================================

Tres cosas, en este orden. Si ya las tienes, salta al paso 2.

1.1 PYTHON 3.10 O SUPERIOR
    Descarga: https://www.python.org/downloads/
    IMPORTANTE: en el instalador, marca la casilla "Add python.exe to PATH".
    Es la casilla que casi todo el mundo olvida y es la causa número uno de que
    el resto no funcione.

    Comprobar que quedó bien (abre una terminal nueva):
        python --version
    Debe responder 3.10 o superior.

1.2 NODE.JS 18 O SUPERIOR
    Descarga: https://nodejs.org  (elige la versión LTS)

    Comprobar:
        node --version
        npm --version

1.3 GOOGLE CHROME
    Si ya lo tienes, nada que hacer. Nova controla tu Chrome real, no una copia
    aislada, así que tus sesiones iniciadas funcionan.

NO hace falta instalar ffmpeg, Visual Studio Build Tools ni el toolkit de CUDA.
Todas las dependencias tienen ruedas precompiladas para Windows, incluidas las
librerías de CUDA: si tienes una GPU NVIDIA, requirements.txt instala por pip
nvidia-cublas-cu12 y nvidia-cudnn-cu12 y Nova las encuentra sola.

Con GPU, transcribir una frase tarda ~0,3 s. Sin GPU, ~1,5 s con el mismo modelo,
así que Nova baja automáticamente a un modelo más pequeño para no hacerte
esperar. Eso es lo único que cambia entre tener tarjeta y no tenerla.


================================================================================
2. INSTALACIÓN (una sola vez)
================================================================================

2.1 Descomprime el zip donde quieras. Ejemplo:  C:\\Users\\TuNombre\\nova
    Evita rutas con acentos o caracteres raros si puedes.

2.2 Abre PowerShell en esa carpeta.
    Truco: en el Explorador, dentro de la carpeta nova, escribe "powershell" en
    la barra de direcciones y pulsa Enter.

2.3 Ejecuta el instalador. UN SOLO COMANDO lo instala todo:

        powershell -ExecutionPolicy Bypass -File scripts\\setup.ps1

    Hace seis cosas seguidas, y tarda entre 10 y 20 minutos la primera vez:
      1. crea un entorno virtual de Python en core\\.venv e instala las
         dependencias del núcleo (ahí va buena parte del tiempo)
      2. instala la voz clonada (PyTorch con CUDA + Chatterbox Turbo, ~4 GB)
         si detecta una GPU NVIDIA; si no, la salta y Nova habla con edge-tts
      3. instala el navegador de Playwright
      4. descarga TODOS los modelos por adelantado: los tres Whisper
         (transcripción, juez de frases cortas y detector de la palabra),
         la palabra activadora sin clave y los pesos de la voz (~2 GB), para
         que el primer "Corrin" no se quede esperando red
      5. instala las dependencias de Electron (npm install)
      6. crea el archivo .env a partir de .env.example

    Opciones:  -SinVoz      sin PyTorch ni Chatterbox (~4 GB menos)
               -SinModelos  los modelos se bajan en el primer arranque
    Es seguro repetirlo: no reinstala ni vuelve a bajar lo que ya está.

    Espacio en disco: unos 8 GB con la voz, ~3,5 GB sin ella. Lo gordo son
    PyTorch con CUDA (~3 GB), los modelos (~3,5 GB entre Whisper medium y la
    voz) y el Chromium de Playwright. Si no tienes GPU NVIDIA, borra las dos
    líneas nvidia-* de core\\requirements.txt antes de instalar.

    Si PowerShell se queja de políticas de ejecución, el "-ExecutionPolicy
    Bypass" del comando ya lo resuelve. No hace falta cambiar nada del sistema.

    ¿Prefieres hacerlo a mano? Es esto:

        cd core
        python -m venv .venv
        .\\.venv\\Scripts\\python.exe -m pip install --upgrade pip
        .\\.venv\\Scripts\\python.exe -m pip install -r requirements.txt
        .\\.venv\\Scripts\\python.exe -m playwright install chromium
        cd ..
        npm install
        copy .env.example .env

    Si más adelante cambian las dependencias de Python no hace falta repetir
    todo esto: basta con

        npm run deps:core            (el núcleo)
        npm run deps:voice           (sólo la voz clonada)
        npm run models:download      (volver a bajar modelos que falten)

    que usan el venv correcto sin que tengas que acordarte de la ruta del
    intérprete.


================================================================================
3. EL ARCHIVO .env — QUÉ PONER
================================================================================

Abre el archivo ".env" que está en la raíz del proyecto (no el .env.example) con
el Bloc de notas o VS Code.

3.1 OBLIGATORIO — LA CLAVE DE DEEPSEEK

    DEEPSEEK_API_KEY=sk-tu_clave_aqui

    Es la única línea imprescindible. Sin esto, Nova arranca pero no piensa.
    Tu clave la sacas de https://platform.deepseek.com → API keys.
    Pégala sin comillas y sin espacios alrededor del signo igual.

3.1b CORREO Y WHATSAPP

    "Envia un correo a juan@gmail.com diciendo..." abre Gmail con todo puesto y
    te pregunta antes de enviar. Si dices que si, lo envia.

    "Manda un WhatsApp a Ana diciendo..." busca el contacto, deja el mensaje
    escrito y te pregunta, nombrando el contacto que leyo en pantalla. Si dices
    que si, lo envia. Si hay varios que encajan, pregunta cual.

    Si solo dices "preparalo", se queda escrito sin enviar. Antes de enviar
    comprueba en pantalla que sigue ahi lo preparado; si algo cambio, no envia.

    Si no tiene la direccion, no entiende el nombre o no encuentra el contacto,
    te pide dictarlo LETRA POR LETRA y te lo repite para que lo confirmes:
        "jota, u, a, ene, arroba, gmail, punto, com"
    Puedes hacer pausas: el dictado termina tras 2,5 s de silencio (se ajusta con
    session.dictation_pause_ms). Para el guion di "guion", y para las dudosas,
    "be larga", "ve chica", "doble u", "i griega". Di "cancela" para dejarlo.

    Donde abre: WhatsApp usa la app si esta instalada. Si no, la pestana de
    WhatsApp Web que tengas abierta, y si no hay, una nueva. Gmail igual: tu
    pestana abierta o una nueva. Nunca duplica ni pisa la que estabas mirando.
    Mientras prepara el mensaje mueve el raton y escribe: no toques nada esos
    segundos. WhatsApp Web tiene que estar en espanol o ingles.

3.1c EXCEL, ENVIOS EN LOTE E IMAGENES

    "Abre clientes.xlsx y manda a cada uno un WhatsApp: Hola {Nombre}, tu saldo
    es {Monto}" lee el Excel (o CSV), arma un mensaje por fila y te pregunta UNA
    vez con un resumen: cuantos, el primero, filas saltadas y cuanto tardara.
    Lo envia en segundo plano, por plazos:
        tandas de 20, 15 min de pausa, 5 s entre mensajes (10 s si son mas
        de 20), tope de 150 al dia
    Se cambia en settings.json, seccion "messaging". Antes de cada tanda avisa
    10 s: en esos minutos Nova usa el raton y el teclado, no toques nada. Si
    Nova esta ocupada contigo, espera. "Como va el envio" y "para el envio".
    Lo enviado queda apuntado: si se corta y lo vuelves a pedir, no repite.
    Salta filas sin telefono, repetidas o con datos vacios. Para numeros sin
    prefijo de pais pon "messaging": {"country_code": "51"} o Nova lo pregunta.
    OJO: WhatsApp puede bloquear una cuenta personal que manda muchos mensajes a
    gente que no la tiene guardada. Para envios grandes y frecuentes, la via
    correcta es WhatsApp Business API.

    "Manda un WhatsApp al 987 654 321" escribe a un numero aunque no este
    guardado, con la misma confirmacion antes de enviar.

    "Lee el comprobante.png y manda el monto a Ana" lee el texto de la imagen
    con RapidOCR: gratis y sin internet. Lee montos, nombres, fechas y
    numeros; no describe fotos. Las cifras pueden salir con errores: revisalas
    en la pregunta de confirmacion antes de decir que si.

3.1d FACTURAS: COBRAR POR WHATSAPP

    "Procesa las facturas de la carpeta Cobros con clientes.xlsx y manda a cada
    uno: Hola {Nombre}, tu factura {Factura} es de {Moneda} {Monto}"

    Las facturas pueden ser imagenes o PDF: el PDF que genera un sistema se lee
    exacto, sin OCR; uno escaneado se lee como una foto. La lista de clientes
    puede ser Excel (.xlsx), CSV o un PDF con la tabla (no escaneado).

    Lee cada factura con RapidOCR (o el texto del PDF), DeepSeek saca el cliente y el monto
    TOTAL a pagar, lo busca en el Excel y le manda el mensaje. NO se para por
    factura ni pregunta: envia directo las seguras y al final te dice cuantas
    salieron y cuales faltan, y deja "Nova - facturas <fecha>.xlsx" en la misma
    carpeta (hojas Enviadas y Pendientes, con el motivo).

    Es "segura" si: el monto aparece tal cual en la factura y se leyo sin duda;
    el cliente se encontro por RUC/DNI o correo exactos, o por un nombre que
    coincide entero (da igual el orden o las tildes) y sin otro cliente igual;
    y tiene un telefono valido. Si no, queda pendiente. Las de monto dudoso las
    puedes mandar luego con "manda tambien las dudosas" (eso SI pregunta, con la
    lista de montos). Repetir la orden no duplica lo ya enviado.

    Tambien puede mandar la factura misma (el PDF o la foto) en vez de un
    mensaje: "...y mandale a cada uno su factura". Si ademas dictas un texto,
    va como comentario del archivo. Si el texto no lleva {Monto}, no hace falta
    que el monto se lea sin duda: el cliente lo ve en la propia factura.

    Si al cliente no lo identifica el nombre sino otro dato, dilo: "guiate del
    codigo de cliente" (o N de suministro, contrato, placa...). Nova busca ese
    dato en cada factura y lo cruza con la columna del Excel que se llame asi,
    o con la que lo contenga si no hay una con ese nombre. Solo usa ese dato, y
    tiene que leerse sin duda: un codigo mal leido podria ser el de otro cliente.

    Las columnas del Excel se reconocen solas (nombre, full name, cliente,
    correo, email, celular, telefono, whatsapp, DNI, RUC...). En el mensaje
    puedes usar {Nombre} {Monto} {Moneda} {Factura} {Fecha} {Correo} {Archivo}
    o cualquier columna del Excel. Los envios van por plazos, como el lote.
    Para que vuelva a preguntar antes de empezar: quita "process_invoices" de
    security.auto_approve en settings.json. Usa DeepSeek: unos centimos por
    cada cientos de facturas.

3.1e CUANDO SE DUERME NOVA

    Una vez despierta (con "Corrin" o Ctrl+Shift+Espacio), Nova sigue
    escuchando sin que repitas "Corrin" y NO se duerme sola por mucho que
    nadie le hable. Se duerme solo cuando le dices "descansa" o con el boton
    de interrumpir (o Ctrl+Shift+X). Mientras esta despierta, todo lo que se
    diga cerca del microfono le llega como orden: en una reunion con altavoces
    o con gente hablando, mandala a descansar. Para que vuelva a dormirse sola
    tras un rato: Ajustes > "Dormirse sola si nadie le habla".

3.2 LA PALABRA ACTIVADORA: "CORRIN"

    Nova se despierta con "Corrin" y con ninguna otra palabra. Funciona sin
    clave ni registro con el motor whisper, que es el predeterminado:

      whisper       ~25 % de GPU  cualquier palabra     sin clave; el predeterminado
      porcupine     ~1 % de CPU   la de tu .ppn         necesita AccessKey y un .ppn
      openwakeword  ~4 % de CPU   sólo "hey jarvis"     sólo si lo pides a mano

    Si el motor no puede reconocer "Corrin", Nova lo avisa en el log y queda
    Ctrl+Shift+Espacio para despertarla. Nunca cambia de palabra por su cuenta.
    Para forzar un motor, en el .env:

        NOVA_WAKE_ENGINE=whisper     (o porcupine, openwakeword, off)

    Picovoice es opcional: sirve para gastar menos en reposo.

        PICOVOICE_ACCESS_KEY=tu_clave_de_picovoice
        NOVA_WAKE_KEYWORD_PATH=C:\ruta\a\corrin_es_windows.ppn

    Cómo conseguirla (es gratis y la clave aparece al instante; si te han
    mandado a un formulario de "contacto con ventas", estabas en el registro
    empresarial y no en el personal):
      1. Regístrate en https://console.picovoice.ai con una cuenta personal
      2. Copia tu AccessKey del panel → esa es PICOVOICE_ACCESS_KEY
      3. Ve a "Porcupine" → crea una wake word con el texto "Corrin"
         → idioma español → plataforma Windows → descarga el archivo .ppn
      4. Guarda el .ppn donde quieras y pon su ruta completa en
         NOVA_WAKE_KEYWORD_PATH

    Si pones la clave pero no el .ppn, Nova usa la palabra integrada "jarvis".
    Si no pones ninguna de las dos, cae a openwakeword. Todas las opciones
    funcionan; cambian el consumo de CPU y qué palabra reconocen.

3.3 OPCIONALES — descoméntalos sólo si los necesitas

    NOVA_STT_MODEL=large-v3
        Modelo de transcripción. Opciones: tiny, base, small, medium, large-v3.
        Por defecto "large-v3", el más preciso (~3 GB, lo descarga el setup o
        "npm run models:download"). Si no está descargado, Nova arranca con el
        mayor que haya y lo avisa en el log, en vez de quedarse esperando la
        descarga sin oírte. Sin GPU usa "tiny" (ajuste stt.cpu_model).
        Si vas justo de memoria (error 1455, la voz no carga), "medium" gasta
        bastante menos y casi no se nota en la precisión.

    NOVA_TTS_VOICE=es-PE-CamilaNeural
        Voz de la respuesta. Otras en español: es-PE-AlexNeural,
        es-MX-DaliaNeural, es-ES-ElviraNeural, es-AR-ElenaNeural.

    NOVA_MOCK=1
        Arranca todo simulado, sin gastar API ni descargar modelos. Úsalo la
        primera vez para comprobar que la interfaz funciona.

    NOVA_NO_INPUT=1
        Desactiva que Nova pueda usar el teclado y el ratón. Recomendado
        mientras te acostumbras a cómo se comporta. Ver sección 8.

    NOVA_LOG_LEVEL=DEBUG
        Logs detallados cuando algo no funcione y quieras ver por qué.


================================================================================
4. CÓMO ARRANCARLO
================================================================================

Desde la carpeta nova, en PowerShell:

    npm run dev:mock     ← EMPIEZA POR AQUÍ la primera vez

        Arranca todo simulado. Sirve para comprobar en 10 segundos que el avatar
        aparece y que la interfaz responde.

        OJO, ESTO CONFUNDE: en modo simulado Nova NO TE ESCUCHA. Las frases que
        aparecen transcritas ("abre el navegador y busca vuelos a cusco",
        "abre spotify"...) son ejemplos en rotación, da igual lo que digas. No
        está entendiéndote mal: no está oyéndote. Para probar el micrófono de
        verdad, usa npm run dev.

        La palabra activadora sí funciona en este modo, porque el detector usa
        su propio modelo.

    npm run dev          ← el modo de verdad

        La primera vez que lo ejecutes descargará el modelo de Whisper
        (unos 500 MB con el modelo "small"). Eso pasa una sola vez y tarda unos
        minutos. Ten paciencia: parece colgado pero está descargando.

Otros comandos disponibles:

    npm run core         Sólo el núcleo Python, con los logs en la terminal.
                         Útil para ver qué está pasando por dentro.
    npm run test:core    Ejecuta las 100 pruebas.
    npm run mic:check    SI NOVA NO TE OYE, EMPIEZA POR AQUÍ. Lista tus
                         micrófonos, graba unos segundos del que use Nova y te
                         dice con números qué falló: el nivel, la palabra
                         activadora o la transcripción.
    npm run deps:core    Reinstala las dependencias de Python en core\\.venv.
    npm run deps:voice   Instala la voz clonada (PyTorch + Chatterbox). Ver §7.
    npm run voice:build  Prepara el audio de referencia de la voz. Ver §7.
    npm run typecheck    Revisa el TypeScript sin compilar.
    npm run build        Compila el TypeScript.
    npm run dist         Genera el instalador .exe en release. Ver §4.1.

Una sola orden, sin interfaz ni micrófono (la forma más rápida de probar):

    cd core
    .\\.venv\\Scripts\\python.exe -m nova.main --text "abre spotify"

4.1 GENERAR EL INSTALADOR (.exe)

    npm run dist

    Deja release\Nova-Setup-0.1.0.exe (77 MB): un instalador normal de
    Windows, por usuario (no pide administrador), que instala en
    %LOCALAPPDATA%\Programs\Nova y crea acceso directo. Dentro va la
    interfaz y el código del núcleo, pero NO el entorno de Python: son 5 GB
    con PyTorch y un venv de Windows no se puede copiar de una máquina a
    otra. Por eso, la primera vez que se abre Nova instalada:

      1. Pregunta si quieres la voz clonada (Chatterbox, ~4 GB más) o no (edge-tts).
      2. Abre una ventana de PowerShell que crea el venv e instala todo dentro
         de la carpeta de Nova. Hace falta Python 3.13 en el PATH e internet.
         Tarda unos minutos.
      3. Crea %APPDATA%\Nova\.env a partir de .env.example y lo abre en el
         Bloc de notas para que pongas la DEEPSEEK_API_KEY.
      4. Al cerrar esa ventana, Nova arranca sola. Las siguientes veces abre
         directamente.

    Instalada, el .env se lee de %APPDATA%\Nova\.env (no de la carpeta del
    programa). Ajustes, memoria, voces y logs siguen en %APPDATA%\Nova.
    Si la instalación del núcleo falla, se puede repetir a mano:
        %LOCALAPPDATA%\Programs\Nova\resources\scripts\instalar-nucleo.ps1 -Voz

    El .exe no va firmado: Windows SmartScreen avisará la primera vez
    ("Más información → Ejecutar de todas formas"). Firmarlo cuesta un
    certificado; para uso propio no hace falta.


================================================================================
5. CÓMO SE USA
================================================================================

Di "Nova" y luego lo que quieras. El avatar aparece en la esquina inferior
derecha mientras te escucha y desaparece solo cuando termina.

Después de responder sigue escuchando unos 12 segundos por si continúas, así que
no tienes que repetir "Nova" en cada frase de la misma conversación.

DOS ÓRDENES QUE OBEDECE AL INSTANTE (sin pasar por el modelo)

    "descansa"   (también "eso es todo", "hasta luego", "adiós", "nada más")
        Se calla si estaba hablando, dice "Okay, resting." y se duerme. Ya no
        sigue escuchando 12 segundos: hay que volver a decir la palabra
        activadora. Lo que dice al despedirse se cambia en settings.json:
        "session": { "farewell": "Okay, resting." }  (vacío = se duerme muda).

    "para"       (también "detente", "cancela", "cállate", "stop")
        Corta lo que esté diciendo O HACIENDO —una cadena de herramientas a
        medias se queda a medias— y vuelve a escuchar por si le das otra orden.

    Las dos valen en cualquier momento: mientras habla, mientras piensa y
    mientras ejecuta. Mientras piensa o ejecuta, el micrófono SÓLO reacciona a
    estas dos; si hablas de otra cosa con alguien, la tarea sigue (y el log lo
    anota como "oído mientras trabajaba (ignorado)").

ATAJOS DE TECLADO

    Ctrl + Shift + Espacio    Despierta a Nova sin hablar
    Ctrl + Shift + X          FRENO DE MANO: interrumpe lo que esté haciendo
    Doble clic en el avatar   Abre los ajustes
    Escape (sobre el avatar)  Cancela la confirmación pendiente

EL AVATAR

    - Arrástralo para moverlo donde quieras; recuerda la posición.
    - Para devolverlo a una esquina: clic derecho en el icono de Nova en la
      bandeja del sistema (junto al reloj) → "Esquina del avatar".
    - El color del halo te dice qué está haciendo:
        azul     en reposo
        verde    escuchándote
        violeta  pensando
        ámbar    ejecutando algo
        rojo     algo falló

EJEMPLOS DE ÓRDENES QUE ENTIENDE

    "Nova, abre Spotify"
    "Nova, busca vuelos a Cusco en enero"
    "Nova, cierra Chrome"
    "Nova, sube el volumen al 30"
    "Nova, busca la imagen que se llama corin"
    "Nova, toma una captura de la ventana de Discord"
    "Nova, busca la imagen corin y pégala en Discord"
    "Nova, lee lo que dice esta página"
    "Nova, baja en Discord y dime qué chats hay"     (hace scroll y vuelve a leer)
    "Nova, sube un poco en Opera"

Para el último tipo de orden — las que tocan archivos y otras aplicaciones —
Nova te va a pedir confirmación. Lee lo que dice el cuadro antes de aceptar: te
dice exactamente qué archivo, en qué aplicación y si lo va a enviar o sólo a
dejar escrito.


================================================================================
6. LA PRIMERA PRUEBA QUE DEBERÍAS HACER
================================================================================

Para comprobar que el control del escritorio funciona de verdad, con Discord
abierto y una imagen cualquiera en tu carpeta de Imágenes:

    1. "Nova, busca la imagen que se llama <el nombre de tu imagen>"
       → debe decirte dónde está.

    2. "Nova, pégala en Discord sin enviarla"
       → te pedirá confirmación. Acepta.
       → la imagen debe quedar adjunta en la caja de texto de Discord, SIN
         enviarse. Tú decides si la mandas.

    3. "Nova, toma una captura de la ventana de Discord"
       → el PNG aparece en tu carpeta Imágenes\\Nova.

    4. "Nova, en Discord abre el chat con <alguien>"
       → Discord salta a esa conversación (usa su buscador rápido, Ctrl+K).
         No pregunta: abrir un chat se deshace abriendo otro.

    5. "Nova, escribe hola qué tal y envíalo"
       → te pregunta «¿Envío "hola qué tal" a <alguien> en Discord?». Aquí
         decides tú: enviar un mensaje no se deshace, por eso pregunta siempre.
       → CONTESTA EN VOZ ALTA: "sí" / "dale" / "vale" envía; "no" / "cancela" /
         "espera" no. Puedes contestar encima de la pregunta, sin esperar a que
         termine. El botón del panel sigue funcionando por si prefieres.
       → Lo que no sea claramente un sí o un no se ignora y sigue esperando
         (te lo dice en pantalla). Ante la duda, nunca es un sí: un "sí" mal
         entendido manda un mensaje que no se deshace; un "no" mal entendido
         sólo te obliga a repetir. Si pasan 30 s sin respuesta, se cancela.
       → La pregunta la oyes en inglés (la voz clonada) con el mensaje en
         español tal cual se va a enviar; en pantalla la ves en español.

    6. Con Discord en la lista de mensajes directos: "Nova, abre el segundo chat"
       → Nova lee la lista de chats de la pantalla, elige el segundo y hace
         clic, sin preguntar. Probado
         contra un Discord real: acierta la columna y el orden.

Si los seis pasos funcionan, todo lo demás también. Abrir chats por nombre
funciona en Discord, Slack y Telegram; en otras apps Nova te dirá que no sabe.


================================================================================
7. LA VOZ CLONADA (opcional)
================================================================================

Nova puede hablar con una voz clonada de unos segundos de audio, en local, sobre
la GPU. El modelo es Chatterbox Turbo (Resemble AI, licencia MIT). Sólo habla
inglés: por eso la voz va en inglés y los subtítulos en español (§3).

7.1 INSTALAR

    Ya lo hace scripts\setup.ps1 (§2.3) cuando detecta una GPU NVIDIA. A mano:

        npm run deps:voice           (PyTorch con CUDA + Chatterbox, ~4 GB)
        npm run models:download      (los pesos del modelo, ~2 GB)

7.2 LA REFERENCIA — VA INCLUIDA

    La voz que Nova clona está en el repo: core\nova\tts\voices\reference.wav
    (34 s, mono, 24 kHz). Quien clone el repo la tiene sin copiar nada más:
    NO hacen falta los audios originales, sólo ese WAV. (No se "entrena"
    nada: el modelo copia el timbre de la referencia en cada frase; ver 7.5.)

    Para clonar OTRA voz:

        npm run voice:build -- "C:\ruta\a\los\audios"

    Junta los audios de la carpeta (ogg, mp3, wav…) en
    %APPDATA%\Nova\voices\reference.wav, que gana sobre la del repo (y
    NOVA_TTS_REFERENCE=ruta.wav en .env gana sobre las dos). El modelo usa los
    primeros 10 s para el timbre fino y 15 para la prosodia, así que lo que
    importa es que empiece por el mejor audio: voz limpia, sin música, sin
    susurros, hablando con naturalidad. Un clip de 10-15 s de diálogo
    tranquilo vale más que un minuto de líneas de combate.

7.3 ACTIVAR

    Nada: el proveedor por defecto es "auto" (voz clonada si está instalada,
    edge-tts si no) y con la voz clonada se habla inglés y se subtitula en
    español solo. Para forzar una cosa u otra, en .env:
        NOVA_TTS_PROVIDER=edge          (o chatterbox)
        NOVA_TTS_SPEAK_LANG=en

7.4 QUÉ ESPERAR

    Medido en una RTX 3050 de portátil: la voz tarda ~0,55 s por cada segundo
    de audio. Una respuesta de 3,5 s empieza a sonar a los ~2 s; las
    respuestas largas se parten por oraciones (la primera corta) y cada
    oración se genera mientras suena la anterior, sin huecos. Frente a XTTS,
    que se usó antes: se parece un poco menos a la referencia (0,61 frente a
    0,64, medido con un codificador de hablante independiente) pero no
    produce basura: 0 tomas malas de 36 contra 5-7, ninguna se desboca y no
    hace falta repetir frases. Las frases de menos de 40 letras se comprueban
    con Whisper antes de sonar por si acaso.

7.5 POR QUÉ NO SE ENTRENA LA VOZ

    Se probó a ajustar XTTS con 3,4 minutos de audio real: ninguna variante
    superó al clonado directo, y las que tocaban el modelo de lenguaje se
    entendían peor. Lo que sí cambia la voz es la referencia (7.2).

8. SEGURIDAD — LÉELO, SON DOS MINUTOS
================================================================================

Nova puede escribir con tu teclado, hacer clic con tu ratón y adjuntar archivos
en tus aplicaciones. Eso es potente y es peligroso. Esto es lo que hay puesto
para que no se te vaya de las manos:

    - Escribir, pulsar atajos, hacer clic y adjuntar archivos SIEMPRE piden
      confirmación. No se puede desactivar esa confirmación. Es a propósito.

    - Nova sólo puede leer archivos dentro de tus carpetas de usuario
      (Escritorio, Documentos, Descargas, Imágenes, Vídeos, Música y OneDrive).
      Cualquier ruta fuera de ahí se rechaza aunque el modelo la pida.

    - Nova NO puede borrar, mover ni renombrar archivos. No están esas
      herramientas. Abrir el archivo equivocado es una molestia; borrarlo no
      tiene vuelta atrás.

    - Ctrl+Shift+X aborta en cualquier momento. Y si empieza a escribir donde no
      debe, escribir tú o mover el ratón gana: Nova no bloquea tu entrada.

    - Si quieres desactivar el teclado y el ratón del todo, pon esto en el .env:
          NOVA_NO_INPUT=1
      O desmárcalo en Ajustes → Permisos → "Control directo del teclado y el
      ratón". Con eso el modelo ni siquiera ve esas herramientas.

Recomendación honesta: usa NOVA_NO_INPUT=1 durante los primeros días, hasta que
veas cómo responde a tus órdenes. El resto de capacidades (abrir apps, navegador,
buscar archivos, capturas) siguen funcionando igual.

9. SI ALGO FALLA
================================================================================

"python no se reconoce como comando"
    No marcaste "Add python.exe to PATH" al instalar. Reinstala Python marcando
    esa casilla, o añade Python al PATH a mano.

"npm no se reconoce como comando"
    Falta Node.js, o no reiniciaste la terminal después de instalarlo. Cierra
    PowerShell y ábrelo de nuevo.

El avatar no aparece
    Mira la terminal donde lanzaste npm run dev. Si dice algo de "núcleo
    terminado", el problema está en Python. Arranca sólo el núcleo con
    "npm run core" para ver el error completo.

Tarda en contestar, o a veces se queda muda
    Cada turno deja en %APPDATA%\Nova\logs\nova-<fecha>.jsonl una línea así:
        turno: modelo 1.4 s · primer audio a 1.9 s · voz adelantada
    "modelo" es lo que tardó DeepSeek (es red: depende de tu conexión);
    "primer audio" es cuándo empezó a sonar desde que dejaste de hablar. Lo
    normal es que el audio empiece ~0,5 s después de que el modelo cierre la
    línea en inglés, sin esperar al subtítulo ("voz adelantada"). Si no pone
    "voz adelantada", el modelo se saltó el formato EN:/ES: y la voz esperó a
    la traducción. Si "primer audio" es -1, no sonó nada: mira justo encima si
    hay un "fallo de síntesis" o si el turno se cortó porque hablaste encima.
    Cada oración que dice deja además una línea "voz: «…» N tokens, X s de
    audio en Y s (rtf 0.55)": cuánto tardó en generarla por cada segundo de
    audio. Lo normal en una RTX 3050 es 0,5-0,6; por encima de 1 la GPU o la
    CPU están saturadas (ver abajo). Las frases de menos de 40 letras llevan
    también "parecido": lo que Whisper entendió de ellas, de 0 a 1; por
    debajo de 0,75 se repite la toma antes de que suene.

Contesta por escrito pero no habla / "error 1455" / "El archivo de paginación
es demasiado pequeño para completar la operación"
    Windows se quedó sin memoria de compromiso (RAM + archivo de paginación)
    al cargar la voz. No es la GPU ni el disco: es que la suma de todo lo
    abierto pasó del tope. Este portátil tiene 8 GB de RAM (7,2 utilizables)
    y un archivo de paginación fijado a 16-24 GB; con el cliente de League,
    Discord, Opera y VS Code abiertos ya van ~22 GB de compromiso, y la voz
    (PyTorch + CUDA + tres modelos de Whisper + Chatterbox) necesita 8-10 GB
    más. En Windows la memoria de la GPU también cuenta contra ese tope.

    Qué hace Nova sola: sigue funcionando por escrito (la respuesta sale en
    el subtítulo y se queda el tiempo de leerla), avisa con "Sin voz ahora
    mismo: te lo dejo escrito", y reintenta cargar la voz a los 30 s, 1, 2,
    5 y 10 minutos. Mientras la voz carga, el avatar está "pensando" con el
    aviso "Preparando la voz...", no "hablando" en silencio.

    Qué hacer tú, de menos a más:
      a) Cerrar el juego o el navegador ANTES de arrancar Nova, o esperar al
         reintento tras cerrar algo.
      b) Agrandar el archivo de paginación (en C: hay ~98 GB libres). En
         PowerShell COMO ADMINISTRADOR:
             $pf = Get-CimInstance Win32_PageFileSetting -Filter "Name='c:\\pagefile.sys'"
             Set-CimInstance -InputObject $pf -Property @{InitialSize=16384; MaximumSize=49152}
         y reiniciar. Equivalente con ventanas: Sistema → Configuración
         avanzada del sistema → Rendimiento: Configuración → Opciones
         avanzadas → Memoria virtual: Cambiar → tamaño máximo 49152 MB (o
         "Tamaño administrado por el sistema").
      c) Más RAM: es lo único que también arregla los 88 s que tardó en
         cargar (estaba paginando todo el rato).

La voz va lenta o se corta SÓLO a ratos
    La voz se genera token a token y eso va limitado por la CPU, no por la
    GPU (medido: la misma frase tarda igual con la GPU fría que a 1,6 GHz).
    Cualquier cosa que compita por la CPU la frena: un cliente de juego
    abierto de fondo (el de League of Legends se comía un 23 % de CPU sin
    estar jugando), un antivirus escaneando, el navegador con muchas pestañas.
    Mira en el Administrador de tareas qué consume CPU y ciérralo. El colchón
    del reproductor evita los cortes, pero no puede hacer que empiece antes.

Abre Chrome en vez de mi navegador
    Nova usa el navegador que tengas abierto, aunque esté minimizado, y si no
    hay ninguno lanza el que pongas en settings.json:
        "browser": { "prefer": "opera" }
    (opera, chrome, edge, brave, firefox o vivaldi). Sin preferido y sin
    navegador abierto, abre su propio Chrome, que es el único que puede
    controlar a fondo (leer la página, rellenar formularios).

"No encuentro el micrófono" o no te escucha
    Windows → Configuración → Privacidad → Micrófono → permite el acceso a las
    aplicaciones de escritorio. Luego, en los ajustes de Nova, elige el
    dispositivo correcto.

"hay GPU pero faltan las librerías de CUDA; se usará la CPU"
    Tienes tarjeta NVIDIA pero no las librerías que necesita CTranslate2. No es
    un detalle: con GPU una frase se transcribe en ~0,3 s y sin ella en ~1,5 s.
    Se arregla sin instalar el toolkit de NVIDIA:

        cd core
        .\.venv\Scripts\python.exe -m pip install nvidia-cublas-cu12 "nvidia-cudnn-cu12>=9,<10"

    Nova añade sola esas carpetas al buscador de DLL de Windows, así que no hay
    que tocar el PATH. Para forzar la CPU a propósito: NOVA_STT_DEVICE=cpu.

Cambié la palabra activadora y sigue respondiendo a la anterior
    Ya no pasa: al guardar desde el panel, la palabra nueva se aplica al momento
    (el panel te lo confirma: "Aplicado ya: palabra activadora «corrin»"). Lo que
    sí necesita reiniciar es cambiar de voz o de modelo.

    Puedes poner varias separadas por comas: "corrin, nova". Y ayuda que la
    palabra sea de dos sílabas y termine en consonante o vocal clara: "Corrin"
    se reconoce mejor que "Nova", que Whisper parte en "no va".

No despierta, o no entiende lo que le digo
    Ejecuta esto antes que nada:

        npm run mic:check

    Te lista los micrófonos, graba seis segundos y te dice en cuál de las tres
    etapas se rompió la cadena. Lo más común, con diferencia, es que Windows esté
    usando un micrófono distinto del que tú crees: en un portátil suele haber tres
    o cuatro entradas (el array integrado, el de la webcam, la "Mezcla estéreo"
    que graba lo que suena en los altavoces...). Si el nivel sale MUDO o MUY BAJO,
    el problema es ése y no Nova.

    Para fijar el micrófono correcto, en %APPDATA%\\Nova\\settings.json:

        "audio": { "input_device": 16 }

    usando el número que te dio mic:check.

    Si el nivel está bien y aun así no despierta, mira en el log qué motor arrancó. Si dice "openWakeWord", alguien
    lo eligió a mano y la palabra es "hey Jarvis", no "Corrin": quita
    NOVA_WAKE_ENGINE del .env y vuelve al motor whisper (ver 3.2).

    OJO CON "HEY JARVIS" SI HABLAS ESPAÑOL. El modelo está entrenado con
    pronunciación inglesa, y la J cambia mucho la cosa. Medido con la misma
    frase dicha de seis maneras:

        inglés nativo ........... 0,993   despierta
        "Éi JARvis" (J inglesa) . 0,888   despierta
        "Ey YARvis" ............. 0,452   NO despierta
        "Ey JÁRvis" (J española)  0,220   NO despierta

    El umbral está en 0,5. Si dices "Jarvis" con J española, no llegará nunca,
    por mucho que grites. Tres salidas, de menos a más esfuerzo:

      1. Pronúncialo a la inglesa: "yei YAR-vis", con la J de "Jessica".
      2. Baja el umbral si mic:check dice que te quedaste cerca:
         "wake": { "oww_threshold": 0.35 }  en settings.json.
      3. Vuelve a "Corrin", que es la palabra normal de Nova:
             NOVA_WAKE_ENGINE=whisper     en el .env
         Ese detector transcribe en vez de comparar huellas, así que entiende
         "Corrin" aunque Whisper lo oiga como "Colin" o "Coring". Gasta más,
         pero desde que usa la GPU la carga bajó del 115 % de un núcleo al 25 %.

    Con el detector por transcripción, Nova reconoce la palabra transcribiendo. Si
    aun así no despierta:
      - habla un poco más fuerte y separado del micrófono
      - arranca con NOVA_LOG_LEVEL=DEBUG y mira en la consola las líneas
        "spotter oyó: ..." — ahí ves exactamente qué está entendiendo
      - mientras tanto, despiértala con Ctrl+Shift+Espacio
    La solución definitiva son los 5 minutos de la clave de Picovoice (ver 3.2).

Error al hablar con DeepSeek, o algo tipo "AsyncOpenAI ... unexpected keyword"
    El cliente de OpenAI cambió de versión mayor. El proyecto está escrito contra
    la serie 1.x y requirements.txt ya la fija, pero si instalaste antes de ese
    arreglo tendrás una versión más nueva. Se corrige así:

        cd core
        .\.venv\Scripts\python.exe -m pip install "openai>=1.40,<2"

Me corta antes de terminar la frase / responde a media frase
    Nova decide que has terminado tras 800 ms de silencio (vad.end_ms). Si haces
    pausas largas para pensar, súbelo en settings.json:
        "vad": { "end_ms": 1200 }
    Cada 100 ms ahí son 100 ms más de espera con la boca cerrada, así que si
    hablas rápido y seguido puedes bajarlo a 500 y ganar tres décimas por frase.


Dice "listo, lo hice" y no ha hecho nada
    Pasó: "abre mi primer chat" → "Listo, abrí tu primer chat" sin haber llamado
    a ninguna herramienta. Ahora, si el modelo afirma una acción («abrí»,
    «envié», «done») en un turno en el que no ejecutó nada, se le devuelve la
    respuesta con un aviso y tiene que elegir: llamar a la herramienta o
    reconocer que no puede. Además las herramientas de chat comprueban el
    resultado: si tras buscar a alguien la ventana de Discord sigue en "Amigos",
    dicen "no encontré a nadie con ese nombre" en vez de "lo envié".

    Para "el segundo chat", "el de arriba", "ese botón": Nova lee la pantalla
    con RapidOCR (read_screen) y hace clic en la línea que corresponda
    (click_item). Antes de cada clic comprueba que en ese punto se ve la
    ventana correcta: si otra la tapa (la barra de Zoom al compartir pantalla),
    prueba otro punto de la misma caja, y si no hay ninguno libre, se para.

    PERMISOS. Tu settings.json tiene "security": { "medium": "auto", "high":
    "auto" }: Nova no pregunta nada de lo que pasa dentro de tu máquina (abrir,
    cerrar, escribir, hacer clic, leer la pantalla). Lo ÚNICO que sigue
    preguntando, y no se puede desactivar, es lo que sale hacia otra persona:
    enviar un mensaje o un archivo. Eso no se deshace y le llega a alguien que
    no configuró Nova. Si quieres volver a que pregunte más, pon "confirm".

Nova se interrumpe sola / responde a cosas que no dije
    El micrófono del portátil oye los altavoces del portátil. Si Nova corta su
    propia respuesta y luego "entiende" basura ("¡Suscríbete!", "Con."), es su
    voz volviendo por el micrófono. Ya hay tres defensas: para interrumpirla
    hace falta hablar por encima de un volumen mínimo (session.barge_in_min_level,
    0.04), durante 400 ms seguidos, y además por encima de 1,8 veces el eco
    que Nova mide durante el primer segundo de cada respuesta (así el umbral
    sigue al volumen de los altavoces). El log lo cuenta: "barge-in: el usuario
    interrumpe (nivel 0.15, umbral 0.07)". Si aun así se interrumpe sola, sube
    el nivel mínimo a 0.06 en settings.json; si usas auriculares, puedes
    bajarlo a 0.01; y si no quieres interrumpirla nunca,
    "session": { "barge_in": false }.

      - Nova le pasa a Whisper una lista de aplicaciones y carpetas como pista.
        AÑADE AHÍ LAS PERSONAS A LAS QUE ESCRIBES: "Alain Ryan" dicho al
        micrófono no se parece a nada que Whisper conozca si no se lo dices.
      - Comprueba con mic:check que no estés AL BORDE DEL RECORTE.
    Si usas programas o contactos que no están en la lista, añádelos en %APPDATA%\\Nova\\settings.json:

    Y comprueba con mic:check que tu micrófono no esté AL BORDE DEL RECORTE: la
    distorsión es lo que más confunde a Whisper con los nombres propios.


Nova olvida lo que le digo entre sesiones
